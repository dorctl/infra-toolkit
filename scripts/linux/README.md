# Linux

Linux servers. `common/` for distribution-agnostic scripts, one folder per distribution for the rest.

## Sub-folders

- [`common/`](common/) - Shell scripts that work on any distribution: disks, LVM, users, SSH, networking, log collection.
- [`redhat/`](redhat/) - RHEL-specific: subscription-manager, dnf / yum, SELinux, RHEL upgrades, satellite registration.
