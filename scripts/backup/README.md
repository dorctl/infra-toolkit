# Backup

Backup software and backup media, one folder per product.

## Sub-folders

- [`tape/`](tape/) - Tape libraries and drives: inventory, media management, drive cleaning, library diagnostics.
- [`veeam/`](veeam/) - Veeam Backup & Replication: jobs, repositories, SureBackup, proxies, reports, configuration backup.
